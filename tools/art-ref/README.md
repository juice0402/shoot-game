## 描き方（このゲームの絵はすべてこの描き方でコードで描く）
1. 部品ごとに形（多角形）を描く。左右対称の部品は、左右をひとつの部品として描く
2. 部品ごとに、ふちからの距離で高さを出す（丸みの大きさは部品ごと：胴体6・翼2.2・飾り1.5・ガラス4・金属2）
3. 高さの傾きから向きを出し、左上からの光で明るさ → 1色5段の色にする（後ろほど少し暗く）
4. 部品の境目は、下・右側の1ドットを暗く（パネルの線）
5. ガラスにキラッと反射のドット、外側に1ドットのふち取り（#060a1c）
6. 炎は白→黄→オレンジ→赤の段で、ゆらゆら動かす
