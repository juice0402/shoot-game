# 強化の設計（試作6・2026-11-15）

しょーくん 11/15「ステージの間の強化もバリエーション必要だと思う！」
→ 2つとも増やす：**道中の強化**（出撃中のレベルアップ）と、**ステージの間の強化**（出撃と出撃のあいだ＝研究所）

## 1. 道中の強化（レベルアップ）
いまの形（3つから1つ・武器／機体／支援）はそのまま。種類を増やす。

| critc | 会心アップ | 会心（2倍）の確率＋4% |

### 進化
- parts.md の「武器の進化」。条件がそろったら、レベルアップの最初の枠に「進化！」（光る枠）

### 宝箱
- 大型の敵を倒すと宝箱が落ちる。拾うと、レベルアップの画面で強化を **必ず3つ** もらえる（えらばずに全部。運で数は変えない＝お金のしくみと関係なし）

### えらび直し・スキップ・除外
- レベルアップの画面に「えらび直し（新しい3つ）」「スキップ（経験値の少しとお金）」「除外（その出撃で二度と出ない）」のボタン。回数は研究所で増やす（はじめは0回）
