# 装備の設計（試作6・2026-11-15）

しょーくん 11/15「銃のパーツやシールド、剣など、色んな発想やバリエーションと機体の特性を、相当な量考えて実装してほしい」「案に関しては全部おすすめでいい」

- いまの19種類はそのまま残す。ここに **50種類** を足して **合計69種類**（攻撃42・防御13・補助14）
- 値段・数字は目安。強さは「レーザー（200G）の Lv1 を 1」として、値段が高いほど少し強い・くせが強いものほど強い
- 絵はすべてコードのドット（tools/art-ref の描き方）。味方の弾・効果は青・黄・緑・紫・白（敵の色＝赤・オレンジ・ピンクは使わない）
- 「向き」がある装備は、つけた向きに撃つ・振る（いまと同じ）。「まわり」と書いた物は向きに関係なく働く
- レベルアップの対象：攻撃すべて・盾ドローン・前面シールド（ほかの防御と補助は、つけた数だけ効く）
- Lv8 で見た目が少し変わる（色が明るく・大きく）
- ショップに並ぶ順（#15）：最初から8こ（レーザー・ガトリング・散弾砲・近接の剣・装甲板・シールド・吸引装置・ブースター）。のこり61こは条件で解放 → [unlocks.md](unlocks.md)

## 武器の進化（14種）
- 武器が Lv8 で、決まった相手の装備をつけていると、次のレベルアップで「進化！」が出る（特別な枠・光る）。えらぶと、その武器が進化の形に変わる（威力が大きく上がり、見た目も変わる）
- 進化は1出撃で何回でも。アルケミスト（ships.md）は Lv6 で進化できる
- ショップのくわしくに「進化：？？？」と出し、1回進化すると相手と名前が見える（図鑑に入る＝upgrades.md）
