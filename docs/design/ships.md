# 機体の設計（試作6・2026-11-15）

- いまの6機（standard・rapid・fortress・collector・blade・carrier）はそのまま。**6機を足して12機**にする
- どの機体にも **必殺技** を1つ足す：画面の下の小さなゲージが、敵を倒す・時間でたまり、いっぱいになると **自動で** 出る（指は機体を動かすだけ、のまま）。ゲージは60秒くらいで1回たまる目安。出るときは画面を少し暗くして、機体の色の光
- 機体の「特性」（skill）は今の形のまま。数字は目安（遊んで直す）
- ブレードの「刃」は、新しい近接（大剣・双剣・ランス・ハンマー・光のムチ・チェーンソー・大鎌）にも効くようにする
- 絵は機体ごとに形と色をはっきり変える（シルエットだけで見分けられる）

## いまの6機に足す必殺技
| 機体 | 必殺技 | しくみ |
|---|---|---|
| スタンダード | 全方位レーザー | 360°に光線を出して、まわりの敵を一気に焼く |
| ラピッド | オーバードライブ | 6秒間、すべての武器の連射が2倍 |
| フォートレス | 要塞バリア | 4秒無敵＋まわりに大きな衝撃波（敵の弾も消す） |
| コレクター | 大吸引 | 画面じゅうの経験値の玉とお金を吸いよせ、まわりの敵に小ダメージ |
| ブレード | 疾風斬り | 画面を横切る3本の斬撃（敵の弾も消す） |
| キャリア | 艦載機発進 | 味方の戦闘機6機が8秒間いっしょに戦う |
