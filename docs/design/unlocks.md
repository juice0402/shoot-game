# はじめの流れとショップの解放（#15・2026-11-16）

しょーくん 11/16「チュートリアル始めたんだけど、機体のここをタップの次に銃選択なんだけど、購入がされてないからいきなり選べなかった。あと解禁されてる銃が最初からフルラインナップだともう、何をしていいかわからなかった。デフォルトから、一番ノーマルな銃を1個だけ持ってて、それを装備して、出撃に誘導するようなチュートリアルでいいと思う」
ショップの品の増え方：「クリアとか、特殊条件とか、ボスクリアでアンロック」

## はじめの流れ

- 新しいセーブ：レーザーを1つだけ持つ。スタンダードの場所は全部空き。お金 300G（前と同じ）
- 遊び方の4枚（見出しだけ）のあと、格納庫で指の案内を3段
  1. 機首（前に撃つ場所）の「＋」を指でさす
  2. 一覧（レーザー のこり 1/1 だけ）の中で、レーザーの行を黄色のわくで目立たせ、すぐ下に指。何もえらばずに閉じたら 1 にもどる
  3. つけたら「出撃」のすぐ上に指（下向き）。出撃したら案内おわり（save.tut=1）
- 板（下から出る一覧など）が開いている間は、板の外の指を出さない（3 の指は場所だけ残して見えなくする）
- 何もつけていないときの出撃ボタン：「＋に装備をつける」
- 前の版のセーブ：tut がなく装備がついていれば 3 から。tut=1 なら何も出さない。試作4の形（持ち物の記録なし）は、そのころのはじめのレーザー2つ
- SHIPS.standard.start（レーザー2つ）はそのまま（試作4のセーブ・ボットのテストで使う）。新しいセーブでつけないだけ。ショップのスタンダードのくわしくには「はじめの武器」を出さない

## ショップの品の解放

- 最初から8こ：攻撃4（レーザー・ガトリング・散弾砲・近接の剣）・防御2（装甲板・シールド）・補助2（吸引装置・ブースター）
- のこり61こに1こずつ条件（index.html の UNLOCK → MODS[t].unlock＝{k,t,n,txt}）。機体の解放と同じ数え方（condCur）を使う
- 条件の種類（しょーくんの言葉どおり3つ）
  - クリア：ステージをはじめてクリア（1〜4）・クリアの回数・HP半分以上でクリア・その品をつけてクリア
  - ボス：大型の敵をたおした数・特定の大型の敵をたおす（図鑑のたおした数）・30秒以内・ノーダメージ
  - 特別：30秒以上の出撃の回数・武器をLv8（種類ごと）・撃破の合計／1出撃の撃破・1出撃のレベル・進化・宝箱・必殺技・近接での撃破・かせいだお金・特別な強化・支援を最大
- 関係のある品でつなぐ：レーザーLv8 → 扇レーザー・追尾レーザー → 扇レーザーLv8 → プリズム砲 ／ ガトリングLv8 → パルス砲・ニードル砲 ／ 近接の剣Lv8 → 大剣・双剣 → 大剣Lv8 → ハンマー・双剣Lv8 → ランス ／ シールドをつけてクリア → 前面シールド → つけてクリア → 盾ドローン ／ 岩喰い → グレネード砲 → Lv8 → クラスター爆弾 など
- お金や運では決まらない（App Store の決まり：お金を払うと運がよくなるしくみは作らない）。解放は記録だけで決まり、品はショップでお金で買う
- 持っている品（owned>0）と、機体を買うとついてくる品は解放ずみ（お知らせなし）
- 機体の解放・実績・進化は、全部いまの解放でたどれる（tools/test/unlock15.py で確かめる）。例：ブレード「近接の剣か回転ノコをLv8」→ 近接の剣は最初から。アルケミスト「武器を1回進化」→ レーザー＋冷却装置（1出撃でLv10）

### 記録

- 足した記録：rec.runs（30秒以上の出撃の回数。すぐ撤退した出撃は数えない #15 の点検）・rec.cw（その品をつけてクリアした回数・種類ごと）。古いセーブは0から（出撃の回数は、クリアの回数・出撃した時間・さいこう記録から少なめに見つもる）
- 大型の敵の種類ごとのたおした数は、図鑑の book.e を使う（#12 の記録）
- お知らせ済みの品：save.unl。#14 までのセーブは、はじめて読んだときに「持っている品＋もう条件を満たした品」をだまって入れる

### 画面

- ショップ：解放ずみの品だけを今の分類で並べる。いちばん下に「もうすぐ解放」：進みぐあいの大きい3こ（シルエット・条件・棒・数）と「のこり ○こ」（3このほかに、まだの品の数）。機体のタブは今のまま
- 「いま買える」の印（タブとショップのボタン）は解放ずみの品だけ。まだの品のくわしくは「まだ解放されていない」
- 出撃の結果：その出撃で解放された品をアイコンつきで「解放：扇レーザー」
- 図鑑：まだの品のヒントは解放の条件（解放ずみでまだ買っていない品は今のまま）
- 出撃中に出てくる強化（レベルアップ・宝箱）は、つけている武器だけ（もともと）。持っていない品が出てくる所はない
