### 重さと起動

GPU のない chromium（ヘッドレス）・幅390 で3回はかった値。

| はかった所 | #12 のあと | #13 のあと | いま（#14） |
|---|---|---|---|
| 起動（スクリプトの始めから終わり・7回の中央値） | 604〜769ms | 827〜902ms | 266〜320ms |
| いちばん重い場面の1フレーム（中央値／95%／最大） | - | - | 10ms／13〜16ms／22〜32ms |
| 出撃の始め（残りの敵と爆発の絵を作る。起動のすぐあとに出撃したとき） | - | - | 310〜350ms |

- 起動：#13 で、全部の敵・大型の敵・機体・装備の絵（装備は8方向と画像のURLまで）を起動のときに作っていた。使うときに作る形にして、タイトルを出したあと、出撃していない間に少しずつ作っておく。敵と爆発の絵は出撃の始めに残りを作るので、出撃中に作ることはない
- 重さ：1フレームの半分が絵を描く時間（drawImage）。GPU で描く端末では、もっと軽くなる見こみ
