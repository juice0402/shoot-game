### BGM（#37・2026-11-17）
すべて C（コードで作った曲）。index.html の SONGS（和音とメロディ）と BGM（鳴らし方）。大きさは BGM_VOL の1か所。
同じ曲を2つの音色で鳴らせる（BGM_STYLE：'chip' ピコピコ・'synth' シンセ）。

| 名前 | 場面 |
|---|---|
| title | タイトル・遊び方 |
| hangar | 格納庫・ショップ・研究所・図鑑・実績・結果のあと |
| st1〜st5 | ステージ1〜5（大型の敵をたおすと、止めた所の小節の頭から続き） |
| boss・final | 大型の敵・最終ボス |
| clear・over | クリア・撃墜のジングル（そのあと hangar）。撤退は hangar |
| ending | エンディング（はじめてステージ5をクリアしたとき） |

- ON・OFF は BGM（save.bgm）と効果音（save.snd）べつべつ。タイトルと一時停止のボタン。save.bgm がない前のセーブは「音」と同じ
- 一時停止の間は小さく。画面が裏に回ると止めて、もどると続きから
